# NomadIQ - Almaty Discovery App

### Project Overview
NomadIQ is an Android application designed for students and tourists to discover "hidden gem" locations in Almaty. It helps users find authentic spots that are often missed by standard travel guides.

### Problem Statement
Many visitors and students in Almaty struggle to find places that match their specific "vibe" (e.g., student-friendly, local secrets). NomadIQ solves this by categorizing places based on experience levels and community-driven tags.

### Tech Stack
* **Language:** Java
* **Architecture:** MVC / Android SDK
* **Network:** Retrofit 2 + OkHttp
* **Maps:** OpenStreetMap (OSMDroid) / Google Maps SDK
* **Backend:** REST API

### How to Run
1. Clone the repository.
2. Open in Android Studio (Ladybug or newer).
3. Build and run on an emulator or physical device.
